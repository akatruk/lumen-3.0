# Lumen · интерактивный UX/UI-макет

Самостоятельный прототип страницы test11, 18 сентября 2026. Рабочий сайт не изменяет.

## Открыть

Из корня репозитория:

```sh
python3 -m http.server 5191 --bind 127.0.0.1 --directory docs/ux/prototype
```

Адрес: http://127.0.0.1:5191

## Что можно проверить

- Один плеер, три настоящих видео, переключение версии и переход к сцене.
- Инструменты «Монтаж», «Субтитры», «Звук», «Эффекты», «Материалы».
- Различие встроенных надписей, новых субтитров и расшифровки.
- Приблизительный просмотр масштаба и демонстрационного текстового слоя.
- Выбор языка озвучки, прослушивание готового русского примера, локальный аудиофайл.
- Проверку изменений перед демонстрационной сборкой. Состояния доступны в верхнем селекторе.
- Выбор конкретной версии перед переходом к реальному скачиванию в рабочем проекте.

AI-ответ заранее подготовлен. Переходы, новая озвучка и рендер не генерируются. Правки не сохраняются после перезагрузки; запросов к API нет. Прокси-видео локальные, уменьшенные до ширины 320 px, не являются файлами для экспорта. MP4 исключены из Git. Доступные локально файлы: assets/effects.mp4, assets/russian.mp4, assets/source.mp4. Кадры сцен иллюстративные, не точный покадровый таймлайн.

## Проверка

Chrome / Playwright, 1440×1000 и 390×844. Проверены воспроизведение, выбор сцен/версий, субтитры, эффекты, проверка правок, состояния сборки и ошибки, локальная музыка, пример AI-ответа, закрытие диалога Escape. Во всех пяти мобильных вкладках нет горизонтального переполнения. Ошибок JavaScript и запросов к API / запросов на изменение данных не зарегистрировано.

Снимки: desktop.png, mobile.png, mobile-subtitles.png. Скрипт smoke.cjs требует установленный Playwright: PLAYWRIGHT_MODULE=/путь/к/playwright node docs/ux/prototype/smoke.cjs. Перед запуском включить локальный сервер.

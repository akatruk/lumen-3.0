# Music rhythm and non-destructive alignment

Private music assets have an explicit cached rhythm-analysis endpoint. Decoding is limited to 420 seconds, 2 kHz mono and 60 seconds processing time. Energy-onset peaks are displayed as estimated accents; BPM is withheld unless there are at least eight sufficiently regular pulses. This is a lightweight onset estimator, not a learned beat/downbeat tracker or emotional classifier.

The editor can align an observed accent with the first approved cut by adjusting only music source_start. It does not retime footage or cut speech. Director Timeline maps observed accents through the selected offset and repeated excerpt. If no suitable accent exists, the alignment control is disabled. EN/ZH copy explains uncertainty.

Validation includes silence/constant audio, a synthetic 120 BPM pulse train, real WAV decoding, cached API access and cross-project denial, and frontend loop/offset/alignment checks. Production TypeScript/Vite build succeeded. No paid AI calls are used.

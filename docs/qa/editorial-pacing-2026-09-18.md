# AI editorial pacing improvements

Creative planning now receives deterministic source-baseline and saved-edit diagnostics and a structured editorial pass covering comprehensible opening, complete speech, justified replay, meaningful pacing, restrained transitions and supported ending. Existing creator preferences, locks, corrected captions, budget bounds and approval remain authoritative. No additional model call, automatic render or cost reservation was introduced.

The review UI shows estimated continuous runs, unchanged contiguous segmentation, longest runs, repeated source duration and transition review cues. Analyzed scene boundaries split runs even within one source clip. Animated/insert-bearing shots are kept separate conservatively. These are timing/settings diagnostics, not visual recognition, authenticity judgments or a quality score. Long speech and purposeful replay remain allowed. Existing clip-length measurements are retained for compatibility; the new metrics expose why splitting an unchanged shot cannot prove better pacing.

All 34 tests passed in an isolated Linux stage, including real rendering. The subsequent source-baseline context addition passed 10 targeted local tests. Production frontend build and all four locale tests passed. Browser fixture confirmed Russian diagnostics, review cues, mobile width and no JavaScript errors. No paid AI run or customer-project mutation; editorial effectiveness remains to be measured on real outputs.
